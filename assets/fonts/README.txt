PRODUCTION FONT NOTE

The design expects self-hosted Fredoka and Nunito in WOFF2 format. Font binaries are intentionally not bundled in this package.
Add your licensed WOFF2 files here as fredoka.woff2 and nunito.woff2, then enable the @font-face declarations in styles.css.
The site currently uses rounded system fallbacks, so it remains fully functional without external font requests.
